# 批量核对与通知

## 触发条件
调用方要求对一批对象按给定口径核对，并对不符项下发提醒。

## 流程
1. 取全量对象清单与基准口径（只取一次）
2. 按片大小上限拆分，逐片派发给数据类子 agent
3. 父侧汇总：去重、统计、统一口径
4. 命中对象交给通知类子 agent，按限流分批下发
5. 回写结果产物，供复核与幂等重跑

## 硬约束
- 分片大小 ≤ 35，超出必须再拆
- 派生事实（如应提交日集合）不转述，只传参数

阶段钩子

onActing · 动作开始/结束（工具请求、工具返回）
onModelCall · 原始模型调用（含 token 用量）
onAgent · Agent 生命周期与子 Agent 事件转发
onError · 异常兜底

onModelCall 维度限流

按 maxContextTokens 提前截断
为什么值得看
Middleware 是唯一能同时看到「模型入参 / 工具请求 / 子 Agent 事件」的地方，也是做观测与治理成本最低的位置 —— 不用改 Agent 代码。
